Reference Manual

Using the USIU Asset Management System

A complete guide to tracking, assigning, inspecting, and maintaining university assets — from signing in to closing a maintenance job.

Audience Students, faculty, technologists, administrators Version 1.0 Updated August 2026

Standard User

Students, faculty, and technologists. Can browse assets, submit requests, and work maintenance jobs assigned to them.

Administrator

Full access: manages assets, users, locations, categories, departments, assignments, inspections, and the audit log.

01

Getting Started

Everything you need before your first session: signing in and understanding what your account can see.

Signing in

  1. Open the Asset Management System in your browser. You'll land on the sign-in screen.
  2. Enter your Email Address and Password.
  3. Select Sign In. If your details don't match, an error banner explains why — check for typos and try again.
  4. On success, you're taken to your Dashboard.
Your account already has a role — Student, Faculty, Technologist, or Admin — set up by an administrator. This role decides which parts of the system you can see and use. It isn't something you change yourself; see Users if you believe yours is wrong.

Signing out

Select Logout in the top navigation bar at any time. This is available on every page once you're signed in.

03

Assets

All Users

The full inventory — every item the university tracks, with its tag, condition, and current status.

Browsing and searching

The Asset Inventory table lists every asset with its Tag, Item, Serial number, Status, and Condition. Narrow the list using the search box or any combination of the filters above the table:

  • Search — free text across tag, item name, and serial number
  • Category, Department, Location — dropdown filters
  • Condition — All Conditions, Excellent, Good, Fair, Poor, Damaged
  • Asset Status — All Statuses, Available, Assigned, Maintenance, Retired

Viewing an asset

Select View on any row to open its details: Asset Tag, Serial Number, Item, Status, Condition, Supplier, Cost, and Purchase Date.

Administrator actions

Admin only

Select Create Asset at the top of the Assets page and fill in the form.

Edit an asset Edit

Select Edit on a row to update Item Name, Serial Number, Supplier, Description, Category, Department, Location, Condition, Purchase Date, or Purchase Cost. Select Save Changes to confirm.

Assign an asset to someone Assign

Only available while an asset's status is Available.

  1. Select Assign on the asset's row.
  2. Search for the recipient by University ID or Name and pick them from the results.
  3. Set an Expected Return Date.
  4. Add any Notes, then select Assign.

The asset now shows as Assigned, and a record appears in Assignments.

04

Requests

All Users

Ask for an asset that's currently assigned to someone else — join the queue, and an administrator approves in order.

This page only lists assets that are currently Assigned to another user. Available assets don't need a request — see Assets to have one assigned to you directly.

Submit a request Request

  1. Find the asset using the search box (matches tag, serial number, or item name).
  2. Select Request on its row.
  3. Enter your Reason for Request — this is required.
  4. Select Submit Request. Your request enters the queue with status Queued.

Check a request queue View Queue

Select View Queue on an asset to see every request against it, in order: Position, requester, Reason, Status, and date requested.

Admin only

Administrators see an Approve button next to each queued request. Approving it records you as the approver and refreshes the queue.

05

Maintenance Jobs

All Users

Jobs assigned to technologists to repair or evaluate flagged assets, usually created from an inspection.

Jobs appear as cards showing the asset, job number, status, priority, who it's assigned to, and a short issue summary. Select View Details to open a job.

Working a job (technologists)

Job statusWhat you can do
QueuedSelect Start Job to begin work.
In ProgressSet Priority, add Resolution Notes, then Save Changes or Complete Job.
CompletedRead-only. Job is closed.

Two checkboxes speed up closing a job: Asset repaired (mark as Fixed) and Asset is not reparable — either one fills in the resolution notes for you. Otherwise, type your own notes.

Not your job? If you open a job that isn't assigned to you, you'll see an Access Denied notice and be returned to the Dashboard automatically after a few seconds.
06

Assignments

Admin Only

A running record of who holds what, and the place to process returns.

The table lists every assignment — asset, who it's assigned to, who assigned it, dates, and status. Use the search box to filter down to one person's assignment history. Select Refresh to pull the latest data.

Process a return Return

Available on any row with status Active.

  1. Select Return on the assignment.
  2. Choose the asset's Condition as it comes back — Excellent, Good, Fair, or Poor.
  3. Add Return Notes if needed.
  4. Select Confirm Return. The assignment closes as Returned, and the asset becomes Available again.
07

Inspections

Admin Only

Scheduled reviews of a batch of assets, ending in a per-asset result and — where needed — a maintenance job.

Schedule an inspection Create Inspection

  1. Select Create Inspection.
  2. Set a Scheduled Date (required) and any Notes.
  3. Search for assets to include — only assets currently Available can be added — and build your Selected Assets list.
  4. Select Create Inspection to confirm.

Moving an inspection forward

Once an inspection is Completed, open it to see one card per asset and fill in:

If you mark a result as Damaged or Needs Repair, a maintenance panel appears — assign a technologist and set a Priority (Low, Medium, High). Select Save Results to submit; this creates a maintenance job automatically for any asset that needs one.

08

Audit Log

Admin Only

A record of every create, update, and delete made across the system — for accountability and troubleshooting.

Each row shows the Time, the Action taken, which record it affected (Entity), and a short Summary. Use the search box to filter, and Prev / Next to page through results.

See exactly what changed View

Select View on a log entry to see the timestamp, who made the change (or "System" for automated changes), a message, and a field-by-field table of old and new values.

Export the log Export CSV

Select Export CSV at the top of the page to download the current log as a spreadsheet file.

09

Categories

Admin Only

The classification used to group assets (e.g. "Laptops", "Lab Equipment") and set how they depreciate.

Select a category on the left to see its Name, Description, and Depreciation Period (in months) on the right.

Create a category Create Category

Fields: Name, Description, and Depreciation Period in months (defaults to 12). Select Create Category to save.

Delete a category Delete Category

Open the category, select Delete Category, and confirm. This cannot be undone.

Categories can be created and deleted, but not edited in place — if details change, delete and recreate the category.
10

Departments

Admin Only

The university departments assets can be attributed to.

Select a department on the left to see its Name, Code, and Description on the right.

Create a department Create Department

Fields: Name, Code, Description. Select Create Department to save.

Delete a department Delete Department

Open the department, select Delete Department, and confirm. This cannot be undone.

11

Locations

Admin Only

Physical places assets live — building and room level.

Select a location on the left to see its Name, Building, Room, and Description on the right.

Create a location Create Location

Fields: Location Name (e.g. "Software Lab"), Building, Room Number, and Description. Name, Building, and Room are required. Select Create Location to save.

Delete a location Delete Location

Open the location, select Delete Location, and confirm. This cannot be undone.

12

Users

Admin Only

Manage every account in the system — creating accounts, adjusting access, and removing them when needed.

Search by university ID or name, or select Reset to return to the full list. Select any row to see that person's University ID, Name, Email, Phone, Role, and Status.

Create a user Create User

University IDRequired
RoleStudent · Faculty · Technologist · Admin (defaults to Student)
First / Last NameRequired
Email / PhoneRequired
PasswordRequired

Suspend or reactivate a user Suspend User / Activate User

Open the user and select the action button — its label switches automatically between Suspend User and Activate User depending on their current status.

Delete a user Delete User

Open the user, select Delete User, and confirm. You cannot delete the account you're currently signed in as.

To return an asset a user is holding, use Return on the Assignments page rather than the Users page.
